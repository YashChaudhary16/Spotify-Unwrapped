# CLAUDE.md

Unwrapped: a privacy-first dashboard for Spotify extended streaming history (Next.js 14 App Router, React 18, TypeScript, Tailwind, Recharts). Uploaded files are parsed in the browser; listening data is never sent to a server.

## Start of every session
- **Read `PLANNING.md` first.** It has the decisions, the Spotify design tokens, the roadmap, "Later / ideas", and a dated Work Log, including ideas the user rejected. Don't re-suggest those.
- For story mode and the "Wrapped Can't Do" features, also read `unwrapped_story_planning.md` (Steps A–V, its own Work Log, open questions).

## Working rules
- **Don't commit or push.** The user reviews and commits. When a change is done, give them ready-to-run `git` commands. Pushing to `main` deploys to production on Vercel.
- **After each change, add a Work Log entry** to `PLANNING.md` (newest on top, using the template in the file), and tick roadmap items.
- Before handing over, run `npx tsc --noEmit`, `npx next lint` and `npm run build`. Say plainly what you verified and what you didn't (e.g. not viewed in a browser).
- Keep the Spotify dark look: colors from the `spotify-*` Tailwind tokens and `lib/chartTheme.ts`; green (`#1ED760`) is for data and active state only.
- Durations are stored in hours. Display them with `formatDuration` / `formatDurationShort` from `lib/format.ts` and `useTimeUnit()`, never with `toFixed`.

## Map
- `lib/preprocessing.ts`: raw export → `ProcessedRecord` (timezones via `lib/countryTimezones.ts`, which is generated by `scripts/generate-country-timezones.mjs`; music only; deduplication)
- `lib/parseFiles.ts`, `lib/parser.worker.ts`: upload parsing in a Web Worker with guard rails
- `lib/analytics.ts`: all dashboard numbers
- `components/Dashboard.tsx`: tabs and the header filter bar; sections live in `components/`; shared UI in `components/ui/`; charts in `components/charts/`
- Spotify artwork without login: `lib/useSpotifyArtwork.ts` (oEmbed, client) and `app/api/spotify/artist/route.ts` with `lib/server/commonsBanner.ts` (artist photo and colors, free-licensed Wikimedia banners)
- "Try with sample data": a real year (2024) of the creator's history in `public/demo/history-2024.json`, built by `scripts/build-demo-history.mjs` (drops private sessions, sleep sounds and IPs) and decoded by `lib/demoHistory.ts`
- `app/api/preprocess`: unused; leave it alone

## Testing gotcha
- To stop a test `next start` server, kill the PID listening on its port (`ss -ltnp`). `pkill -f "next start …"` matches its own shell and leaves the server running.
